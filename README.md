#**Rôle de chaque module :**

| Fichier           | Rôle                               |
| ----------------- | ---------------------------------- |
| **ui.py**         | Interface utilisateur              |
| **auto_debug.py** | Boucle d’auto-débuggage            |

| **ai_client.py**  | Appel à l’IA + prompt              |
| **patcher.py**    | Application des patchs             |
| **config.py**     | Gestion des paramètres persistants |
